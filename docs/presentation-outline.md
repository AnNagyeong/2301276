# 상권.zip 발표 구성

이 문서는 발표용 초안입니다. 실제 데이터 수치나 배포 성공을 가정하지 않습니다.

## 1. 프로젝트 제목과 개발 동기
상권.zip: 창업 전에 동네의 경쟁 환경을 공공데이터로 살펴보는 웹앱. 점포 목록 조회에서 나아가 밀도와 다양성을 직접 계산한다.

## 2. 서비스 목적과 사용자
예비 창업자가 지역과 희망 업종을 선택하고 두 지역을 동일 조건으로 비교한다. 매출이나 성공률을 예측하지 않는다.

## 3. 공공데이터 API
소상공인시장진흥공단 상가(상권)정보 API. https://www.data.go.kr/data/15012005/openapi.do
반경 내 상가업소 조회(storeListInRadius), JSON/XML 지원. 상가업소 ID, 좌표, 소분류 코드와 명칭을 사용한다.

## 4. 시스템 아키텍처
GitHub Secrets → GitHub Actions(Node 수집기) → 정제된 정적 JSON → GitHub Pages → 브라우저 분석/지도/차트.
브라우저에 API 키를 전달하지 않는 구조다.

## 5. 데이터 처리
API 페이지네이션과 전체 건수 확인 → ID 중복 제거 → 좌표/업종 검증 → 배치별 저장 → 모든 지역 성공 시 공개 메타데이터 교체. 실패 시 이전 정상 데이터와 수집 시각/실패 상태 표시.
Secret 재등록 후 실제 JSON 수집 성공. 성수 8,608건, 홍대 12,985건, 강남 17,504건으로 합계 39,097건이다. 중복·검증 제외는 0건이며 기준년월은 응답에 없어 미제공으로 표시한다.

## 6. Haversine
위도·경도를 라디안으로 바꾸고 구면의 두 점 사이 거리를 구한다. 지구 반경 6,371km. 반경 경계는 포함한다. 도보거리가 아닌 직선거리다.

## 7. 경쟁 밀도
경쟁업체 수 / [π × 반경(km)²]. 단위는 곳/km². 점포 수와 밀도를 다른 KPI로 표시한다.

## 8. Shannon Entropy
H=−Σ(pᵢ ln pᵢ), pᵢ는 소분류별 점포 비중. 관측 소분류 수 k로 H/ln k 정규화. 한 업종은 0, 무점포는 계산 불가다. 관측 업종 수가 다르면 정규화 수치 해석에 주의한다.

## 9. 웹페이지
- 검색: 지역·소분류·반경 선택, 중심 지도, 이전 조건 저장.
- 분석: 점포 마커, 경쟁업체 필터, 4개 KPI, 분포 차트/표, CSV.
- 비교: 지역 A/B, 공통 업종·반경, 경쟁 점포 막대그래프, 지표 차이와 해석.
실제 수집 데이터로 동작하는 분석 화면을 마지막 페이지에 첨부한다.

## 10. 테스트
Node 내장 테스트 16개 통과, 0개 실패. 실제 API 수집과 데스크톱·모바일 화면, 지역 비교 검증. 성수 500m 카페 117곳·전체 3,160곳·밀도 148.97곳/km², 홍대 카페 292곳으로 화면과 모듈 계산이 일치한다.

## 12. 결과와 한계
독립 HTML 3개와 자체 분석 알고리즘, 정적 수집 구조 구현. 고정된 세 지역 1km 범위만 지원한다. 원천 데이터의 정확도와 갱신 시차에 영향을 받는다. 원천 기준년월 미제공, 고정 수집 범위, 원천 데이터의 갱신 시차와 누락 가능성이 한계다. XML은 fixture 테스트를 통과했으나 실제 수집은 JSON으로 검증했다.



## 추가 구현: 닮은 동네의 계산 근거 시각화
소분류 비중 벡터로 코사인 유사도를 직접 구현한다. 업종별 내적 항의 비율로 산식을 분해하고, 상위 6개 업종의 비중을 두 지역의 나란한 막대로 표현한다. 차이가 큰 4개 업종도 병행해 공통으로 비중이 크다는 것과 비중이 동일하다는 것을 구분한다. 전체 업종 표, 0벡터·무공통업종·30곳 미만 표본 처리와 테스트를 설명한다. 실제 화면은 사이트의 닮은 동네 영역에서 확인한다.
